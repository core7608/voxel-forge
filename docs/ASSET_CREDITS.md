# Asset Credits

Every 3D asset in this project is a **real imported model** from the two
approved sources below (per the project brief). No procedural placeholders are
used for blocks, characters, weapons, or furniture — the code falls back to a
simple shape only if a model file is missing (logged as a warning), so a
missing asset is always visible, never silently faked.

All assets are **CC0 (public domain)** — free for commercial use, no
attribution legally required. Credit is given here for project hygiene and to
help contributors.

cell) by `scripts/voxel/block_model_baker.gd` and instanced into the chunk
mesh.

## KayKit — [kaylousberg.itch.io](https://kaylousberg.itch.io) · CC0

> **Note:** KayKit packs are distributed on itch.io and require an e-mail even
> for the free tier, so they could **not** be auto-downloaded into this
> repo. The game deliberately uses Kenney's stylistically-matching low-poly
> models instead (same category, same low-poly cartoon look) so every asset is
> present, documented, and CC0.
>
> To add KayKit (optional, e.g. richer characters or dungeon props): download
> the pack (free), drop the `.glb` files into `assets/kaykit/<pack>/`, then
> point the relevant `MODEL_PATH` constants at them:
> - Player/Villager/Monster: `scripts/player/player.gd`, `scripts/npc/villager.gd`, `scripts/npc/monster.gd`
> - Blocks: `tools/gen_tres.py` (set a model path)
> - Furniture: `scripts/systems/furniture_catalog.gd` (add a `"src"` folder)
>
> Recommended packs: **KayKit Adventurers** (characters/tools),
> **KayKit Dungeon Remastered** (monsters/dungeon props).

## Placeholder/generated assets (NOT game 3D assets)

- `assets/generated/blocks_atlas.png`, `icons.png` — 2D textures for the hotbar
  icons and the **unit-cube fallback** (only used if a block has no model).
- `assets/generated/default_skin.png` — default skin for the player's
  fallback capsule body (the real player uses the Kenney model).
- `assets/skins/` — user-importable skins (PNG).

These are generated by `tools/gen_assets.py` (pure Python stdlib) and are UI
textures / fallbacks, not the in-game 3D models.
