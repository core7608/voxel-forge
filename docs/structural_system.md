# نظام الفيزياء الإنشائية — التوثيق التقني

الميزة المحورية للعبة: بناء **واقعي منطقي** بدون تحويل اللعبة لمحاكاة إجهاد هندسية.

## المبادئ

1. **Support (الدعم)** — كل بلوك "غير أرضي" لازم يكون جزء من سلسلة دعم توصل للأرض أو لبلوك **Foundation** واقف على الأرض.
2. **Span (المدى الأفقي)** — كل مادة لها `max_span`: أقصى عدد بلوكات أفقية "برّاية" من سلسلة الدعم. التراكب **العمودي** مجاني (ده اللي بيبني الـ Pillar).
3. **Load (الحمل)** — كل بلوك يتحمل وزن البلوكات **فوقه في نفس العمود** بحد `support_value` (محاكاة مبسّطة لأحمال الـ Pillar; التوزيع الأفقي للحمولة في نسخة C# القادمة).
4. **Terrain = جذور دائمة** — التضاريس (Grass/Dirt/Stone/Sand/Bedrock) دائماً مدعومة. الرمل أرضية "ليّنة": أي بلوك يتوضع فوقه يبدأ بـ +1 على المسافة (Penalty بسيط).

## الحلّ الخوارزمي (Flood-fill / Relaxation)

```
seed:   كل بلوك واقف على أرض  → d = 0   (أو 1 لو فوق رمال)
loop:   pop p from queue
        up:      d[up] = d[p]            (عمودي = مجاني, cost 0)
        sides:   d[side] = d[p] + 1      (أفقي, cost 1)
                 بشرط: d[side] <= max_span(material[side])
```

- البلوك اللي **ما وصله دعم** → `UNSTABLE`.
- `d == max_span` → `WARN` (أصفر في الـ Ghost / على البلوك).
- `load > support_value` → `UNSTABLE` · `> 80%` → `WARN`.

**التكلفة**: O(n) على بلوكات اللاعب الموضوعة فقط (مش كل الخلايا). إعادة الحساب **Debounced** (مرة كل frame كحد أقصى عند تغيير). عالم الـ Prototype (96×96) بيعدّي بالمللي-ثواني في GDScript.

## الدورة الزمنية للانهيار

```
وضع بلوك → recompute → غير مدعوم؟
   ├─ لا  → OK/WARN (لون الغوست/البلوك)
   └─ نعم → UNSTABLE:
             1. توهج أحمر نابض + خط شرخ + صوت + بانر HUD بعدّاد
             2. مهلة GRACE_SECONDS = 12s (تتعدّل: structural.GRACE_SECONDS)
             3. لو اتضاف دعم خلال المهلة → ترجع MDعومة (الحالة تتحدّث live)
             4. انتهت المهلة → الجزء الغير مدعوم كله:
                  set_block(air) + RigidBody3D مؤقت (4 ثواني)
                  يسقط/ينعكس ضد شبكة الـ Voxel + 50% يخلّف Pickup
```

ملاحظة أداء (مقصودة): **مفيش physics bodies للبلوكات طول الوقت** — الـ RigidBody بيتفعّل *فقط* وقت الانهيار وبيتم تكامله يدوياً ضد شبكة الفوكسل (`VoxelMover`) وبعدين بيتفرمل.

## الـ Ghost Preview

قبل التأكيد: `StructuralIntegrity.preview(pos, mat)` = نفس الـ solver مع البلوك الافتراضي:
- **أخضر**: مدعوم بارتياح · **أصفر**: على الحد بالظبط · **أحمر**: هيقع.

## Structural Info Mode (V)

لكل بلوك محدد: خط الدعم من البلوك لجذره (يسير `parent_of` من الـ solver) + تسمية:
`span d/max · load/cap · OK|NEAR LIMIT|UNSTABLE`.
